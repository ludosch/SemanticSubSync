Re-times the external .srt subtitles of movies and episodes on the subtitle embedded in the video, by matching lines on meaning. When too few lines match, the file is left alone.

New subtitles are processed automatically: when a video is added, and with the scheduled task Re-time new subtitles (Dashboard > Scheduled Tasks) for the subtitle files added or changed later, e.g. by Bazarr. Any movie or episode, now: Sync subtitles in its menu.

The engine and its model (about 400 MB) are installed in the plugin's data folder, in the background, a few minutes after Jellyfin starts. Jellyfin needs write access to the media folders.

Off: when a subtitle is corrected, the subtitle as downloaded stays in the player's list as an extra "untouched" track, to switch to if the correction is wrong. On: it is kept in the same folder under a name the player ignores (.srt.orig), so only the correction shows. Changing this renames the kept files the next time the subtitles are checked.
