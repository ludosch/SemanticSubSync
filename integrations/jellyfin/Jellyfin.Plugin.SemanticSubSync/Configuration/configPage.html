Re-times the external .srt subtitles of movies and episodes on the subtitle embedded in the video, by matching lines on meaning. When too few lines match, the file is left alone. Runs when a video is added and with the scheduled task Re-time new subtitles (Dashboard > Scheduled Tasks).

The engine (about 500 MB with its model) is installed in the plugin's data folder on first use. Jellyfin needs write access to the media folders.

Applies to the first run only. Off: the subtitles already there are left as they are, and only the ones added later are processed. On a large library and a small server, processing everything can take hours.
Leave empty for the release this plugin was built for. A wheel path or URL installs that build instead.
